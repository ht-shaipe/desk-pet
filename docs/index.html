Features

一只精灵，十二件顺手的小事

所有能力都收在同一块面板里，不打断你手上的工作。

常驻桌面

透明无边框、始终置顶、不占任务栏，跟随所有工作区；头像可换成任意图片。

自由拖拽

按住精灵拖到任意位置，松手即记忆；重启回到原处，靠近屏幕边缘自动钳制。

单击展开

待命时只占 72 × 72，单击展开工作台；再次点击精灵或右上角按钮即可收起。

快速启动器

应用、网址、命令三类入口按分类展示，支持增删改，可自定义图标与颜色，常用入口一屏直达。

便签

随手记录、多色彩区分，输入防抖自动保存，切走或重启都不会丢内容。

番茄钟

专注 / 短休 / 长休循环，到点系统通知；基于时间戳计时，不受后台节流影响。

剪贴板历史

自动捕获文本，最多 100 条；支持搜索、链接高亮、一键回贴、单条删除与清空。

快捷操作

深浅模式切换、静音、锁屏、睡眠，以及系统设置各子页一键直达。

工具箱

注册表式小工具集合，按需懒加载；内置二维码生成与解析，新增工具只需三步。

账户

手机号注册 / 登录，远端图形验证码 + 滑块人机验证，凭证仅保存在本地。

系统集成

托盘菜单、全局快捷键、开机自启、单实例，以及中文 / 英文界面随时切换。

自动更新

启动静默检查、每 6 小时轮询；发现新版本推送通知，签名校验后直接安装。

Architecture

三层结构，各司其职

UI、外壳与系统能力彼此解耦，核心 crate 不依赖 Tauri，可独立测试。

src/

前端应用

Vue 3 单页应用：views 页面、components 组件、Pinia 状态，api 按域封装。

src-tauri/

Tauri 外壳

窗口、托盘、插件注册与命令分发；命令是薄壳，直接委托给 Rust crates。

deskpet-store

数据层

SQLite（WAL 模式）持久化、设置读写、头像管理，不依赖 Tauri，可独立测试。

deskpet-os

系统层

应用启动、快捷操作、剪贴板访问与文件落盘，屏蔽平台差异。

数据都在本地

SQLite（deskpet.db）保存便签、剪贴板与启动项，settings.json 保存设置，位于 ~/Library/Application Support/com.deskpet.desktop/ （Windows 为 %APPDATA%\com.deskpet.desktop\）。

已知限制

  • 精灵窗口为矩形，透明边角仍会遮挡下方桌面的点击（点击穿透暂未实现）。
  • 置顶窗口无法悬浮在 macOS 原生全屏应用之上。
  • 剪贴板历史仅记录文本，不包含图片。
  • Linux（尤其 Wayland 下的透明与置顶）暂不在支持范围。
  • 透明窗口依赖 macOS 私有 API，因此不通过 Mac App Store 分发。

Get started

下载，或者自己构建

安装包由 GitHub Actions 自动构建：推送 v* 标签后，macOS（arm64 / x64）与 Windows 版本会同步产出，并附带签名更新清单。

前往 Releases 阅读文档
  • 前置要求Node.js 20+、Rust stable 工具链
  • 体积轻量复用系统 WebView，不打包 Chromium
  • 更新有签名Tauri Updater 校验后再安装
  • 数据可迁移首次启动自动迁移旧版 JSON 并保留备份
