# 功能使用手册

本文面向使用者，按界面模块说明每个功能怎么用、会产生什么数据、有哪些边界。
开发实现细节见 [architecture.md](architecture.md) 与 [development.md](development.md)。

## 1. 启动与桌面精灵

### 1.1 首次启动

1. 启动后精灵出现在主显示器**右下角**（距右 32pt、距底 96pt，按屏幕缩放比换算）。
2. 主窗口以 `visible: false` 创建，前端首帧绘制完成后才显示，避免透明窗首帧灰底闪烁。
3. 首次使用深浅模式 / 静音等 macOS 自动化能力时，系统会弹窗要求授权。
4. 如需在「系统设置 → 隐私与安全性 → 完全磁盘访问」中授权，可从磁盘清理工具内的引导按钮直达。

### 1.2 精灵操作

| 操作 | 行为 |
| --- | --- |
| 单击精灵 | 展开面板 |
| 再次单击精灵 / 点面板右上角按钮 | 收起面板 |
| 按住拖动 | 移动精灵；位置持久化，重启恢复 |
| 拖到屏幕外 | 自动钳制回可见区域 |
| 面板边缘 / 四角拖动 | 调整面板大小（最小 300×420），下次展开沿用 |
| `Command/Ctrl + Shift + P` | 显示 / 隐藏主窗口 |
| 收起态悬浮 | 可显示时钟、今日 AI 用量徽标（番茄钟运行时优先显示倒计时） |

> 精灵尺寸可在设置中调整（32–96），折叠窗口会随尺寸放大，视觉中心保持不动。

### 1.3 面板结构

面板自上而下：

1. 头部：应用名 + 收起按钮；空白区可拖动窗口（4px 位移阈值，避免点击误触）。
2. 标签导航：8 个标签，点击切换；番茄钟运行时标签提示会附带剩余时间。
3. 内容区：各页面自行管理滚动。

> 标签内容按需渲染，切换标签不会重建整个面板。

## 2. 面板标签页

### 2.1 快速启动（`launcher`）

页面顶部有两个子标签：**启动器** 与 **快捷操作**。

启动器：

- 三类入口：**应用** / **网址** / **命令**，按类型分组展示。
- 添加 / 编辑：名称、类型、内容、图标（Emoji 或单字，留空取名称首字）、颜色。
- 应用类型支持从已安装应用中选择并自动提取图标；也可填写应用名或程序路径。
- 网址用系统默认浏览器打开；命令用系统 shell 执行。
- 管理态可删除条目、快速往空分类添加。

快捷操作（仅 macOS 显示深浅模式与静音）：

| 操作 | macOS | Windows |
| --- | --- | --- |
| 深浅模式切换 | 支持（首次需自动化授权） | 不支持 |
| 静音切换 | 支持 | 不支持 |
| 锁屏 | 支持 | 支持 |
| 睡眠 | 支持 | 支持 |
| 系统设置 / 声音 / 显示 / 网络 | 支持 | 支持 |

### 2.2 番茄钟（`pomodoro`）

- 三种模式：**专注**（默认 25 分钟）、**短休息**（5）、**长休息**（15）。
- 模式按钮右侧的齿轮可分别调整三种时长（1–120 分钟）。
- 开始 / 暂停 / 重置；未运行时修改时长会立即同步到当前模式。
- 每完成 4 次专注，自动进入长休息；其余专注结束进入短休息。
- 阶段结束时：
  - 发送系统通知（首次会请求通知权限）；
  - 向 `notify` 窗口发送 `pomodoro://session-done`，弹出屏幕中央提醒浮层，点击任意处或按 Esc 关闭。
- 剩余时间基于结束时间戳计算，即使 WebView 定时器被节流也不会漂移。
- 已完成专注次数显示在标题右侧，仅保存在当前会话内存中。

### 2.3 剪贴板（`clipboard`）

自动捕获系统剪贴板（文本与图片），按更新时间倒序展示。

- **搜索**：按内容过滤。
- **类型筛选**：全部 / 文本 / 网址 / JSON / SQL / 图片。
- **重复计数**：相同内容再次复制时累计次数并提示。
- **回贴**：点击条目复制回系统剪贴板。
- **条目操作**：删除单条；网址条目可打开链接、加入收藏；文本可加到便签（收藏中的 note）。
- **批量清理**：按当前筛选结果、网址、SQL、图片、JSON、文本、7 天前或全部清空。
- **云同步**：设置中开启后，可手动推送 / 拉取；仅同步文本，图片只保留本地。

数据：

- 文本条目存 `clipboard.text`；图片条目存 `clip_images/<id>.png`，`text` 字段记录文件名。
- 图片按 RGBA 字节 FNV-1a 64 签名跨重启去重。
- 历史条目上限由 Rust 侧维护，超出后淘汰旧条目并清理图片文件。

### 2.4 收藏（`stash`）

统一管理网页、仓库、文章、视频、商品、社交、图片、书签与便签。

- **添加收藏**：地址、名称、类型、分类、描述、标签。
- **便签**：类型为 `note`，正文与颜色保存在 `payload` JSON 中；旧版独立便签已自动迁入收藏。
- **分类**：19 个内置分类（AI/Agent、前端框架、后端框架、UI 组件库、工具链/构建、DevOps、数据库、网络、安全、测试、文档、运维、移动端、桌面端、游戏、音视频、区块链、编程语言、其他）。
- **搜索 / 筛选**：关键词 + 分类。
- **菜单操作**：导入 JSON、导出 JSON、刷新 GitHub/Gitee 仓库数据、立即同步、拉取数据、清空收藏。
- **仓库数据刷新**：调用 GitHub / Gitee 公开 API 更新 stars、forks、languages。
- **云同步**：全量 upsert + 全量游标分页拉取 + 云端删除墓碑；本地 `update_time` 更新的记录不会被旧云数据覆盖。
- **去重**：同一地址再次添加会提示覆盖。

数据字段保持 `snake_case`（`fav_type`、`category_name`、`create_time`、`update_time`），与云端契约一致。

### 2.5 工具箱（`toolbox`）

首页卡片列表 + 详情页。工具组件懒加载，进入详情时才载入。当前 11 个工具见下一节。

### 2.6 AI 助手（`chat`）

- 在设置 / 对话页配置一个或多个 OpenAI 兼容模型（名称、`base_url`、`api_key`、模型名），选择当前模型。
- 支持流式输出、Markdown 渲染、代码块、复制消息。
- **内置工具**：
  - `list_apps`：列出本机已安装应用；
  - `open_app`：按名称 / 别名 / 模糊匹配启动应用；
  - `open_pomodoro`：打开并操作番茄钟；
  - `open_view`：切换到应用内视图；
  - `open_tool`：打开工具箱工具。
- **MCP 工具**：配置并连接 MCP 服务器后，其工具会暴露给模型；调用前弹出确认框。
- **聊天记录**：落 SQLite，支持删除单条、从某条起截断并重试、清空。
- **降级**：模型不支持 function-calling 时，首次 4xx 后自动按普通对话继续。
- **本地 / 内网自签名证书**：仅对本机与私有网段的 `https` 地址做忽略证书重试，公网地址保持严格校验。

### 2.7 账户（`account`）

- 手机号 + 密码登录 / 注册。
- 人机验证支持图形验证码与滑块两种模式，由服务端配置决定。
- 登录成功后 token 与手机号保存在 `settings.json`；云同步复用该 token。
- 登出时会向实时通道发送显式解绑帧，然后以匿名身份重连。

### 2.8 设置（`settings`）

三组设置：

**通用**

- 应用名称（面板与托盘显示，最长 24 字）
- 语言：中文 / English
- 开机自启
- 显示 / 隐藏快捷键说明
- 在 Dock 中显示（仅 macOS）
- 宠物时钟（收起态显示当前时间）
- 宠物 AI 用量徽标（收起态显示今日 token 总量）

**外观**

- 主题：浅色 / 深色 / 跟随系统
- 精灵图标大小（32–96）
- 精灵头像：更换图片 / 恢复默认（PNG/JPG/GIF/WebP/BMP）
- 主题色：预设色或自定义色值
- 窗口置顶

**关于**

- 当前版本
- 检查更新：检查中 / 下载进度 / 重启安装 / 已是最新
- 更新失败提示

## 3. 工具箱工具

### 3.1 二维码（`qr`）

- 生成：输入文本或链接，选择尺寸，生成二维码。
- 解析：粘贴剪贴板图片或选择本地图片，识别其中的二维码。
- 支持复制图片、保存 PNG（保存后自动在文件管理器中定位）。

### 3.2 Base64（`base64`）

- 文本 → Base64 编码；Base64 → 文本解码。
- 非法 Base64 会提示；支持「结果转输入」与复制。

### 3.3 DES 加解密（`des`）

- DES ECB 模式，密文以 Base64 展示。
- 密钥建议 8 位；加密失败时检查密钥与密文格式。
- 仅用于本地轻量场景，不建议用于生产级敏感数据保护。

### 3.4 图片压缩（`imgcompress`）

- 输入：粘贴剪贴板图片、选择本地图片，或打开图库。
- 四种方案：智能平衡 / 高画质 / 极小体积 / 自定义。
- 参数：画质、长边上限、输出格式（智能择优 / 保持原格式）、目标体积（KB，0 为关闭）。
- 水印：无 / 文字 / 图片 / 盲水印；可设置内容、字号、颜色、不透明度、旋转、铺满或单枚、密度、位置。
- 批量：选择目录，按当前设置给出精确预估，压缩到所选目录的 `compressed/` 子目录。
- 若重编码后体积未减小，会保留原图并提示「已最优」。

### 3.5 接口请求（`http`）

- 在独立窗口中填写 URL、方法、参数、请求头、请求体（JSON / 文本）。
- 由 Rust 代理发送，不受 WebView 跨域限制。
- 展示响应体、响应头、请求头、最终地址、耗时与体积；超大响应只展示前 2 MB，二进制响应不展示内容。
- 可复制响应体。

### 3.6 磁盘清理（`cleanup`）

- 选择根目录（默认家目录）与日志保留天数（默认 7 天）。
- 扫描缓存、构建产物、依赖、日志、废纸篓、下载等可回收项；结果按类别筛选。
- 每类最多直接渲染 60 条，避免上千条 DOM 卡顿。
- 扫描过程中显示目录 / 文件 / 字节进度，可取消。
- **复核清单**：删除前生成计划，展示每项大小、文件数、风险与回收站 / 永久删除模式。
- 删除默认走系统回收站，永久删除不可恢复。
- macOS 无「完全磁盘访问」时提供一键打开系统设置引导。
- 「分析」按钮打开独立磁盘分析窗口（见 4.1）。

### 3.7 文档转换（`docconv`）

- 打开文档管理窗口，管理文档目录。
- 支持将 PDF / DOC / DOCX / PPT / PPTX / XLS / XLSX / ODT / ODS / ODP / RTF / EPUB / CSV / MD / TXT 转为 Markdown。
- 扫描版 PDF 无文本层时返回 `needs_ocr` 与无文本页列表，需外部 OCR。
- 转换结果可保存为 `.md`。

### 3.8 系统监控（`monitor`）

- 实时展示 CPU（总量 + 每核）、内存、网络上下行与累计流量、磁盘卷空间。
- 刷新间隔 1s / 2s / 5s，工具页、悬浮监控条、菜单栏共用。
- 可暂停 / 继续。
- **悬浮监控条**：无边框置顶小窗，可鼠标穿透、按 CPU / 内存 / 网速分区显示；位置记忆。
- **菜单栏监控**（仅 macOS）：在状态项上绘制双行芯片文字，可选择是否保留桌宠托盘图标。

### 3.9 文本对比（`textdiff`）

- 独立窗口，左右输入或粘贴两段文本。
- 行级 diff + 词级差异高亮，支持语法高亮语言选择。
- 展示新增 / 删除行数，可一键清空或交换。
- 支持语言：Rust、JavaScript、TypeScript、Python、JSON、CSS、HTML、Go、Java、C、C++、YAML 等（tree-sitter）。

### 3.10 代码格式化（`formatter`）

- 基于 Prettier standalone，支持自动检测或手动选择：
  JSON、JavaScript、TypeScript、HTML、Vue、CSS、SCSS、LESS、YAML。
- 缩进：2 空格 / 4 空格 / Tab。
- 显示格式化后的字符数与行数，可复制或清空。

### 3.11 AI 用量（`aiusage`）

- 统计本机 AI 编程工具的 token 用量与成本。
- 数据来源：
  - Claude Code：`~/.claude/projects/<proj>/<session>.jsonl`；
  - Codex CLI：`~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl`；
  - OpenCode：本地 SQLite 消息库。
- 增量扫描：文件 size / mtime 未变即跳过；后台每 5 分钟扫描一次，也可手动刷新。
- 范围：今日 / 昨日 / 本周 / 本月。
- 成本：优先使用日志中的真实成本（OpenCode），其余按内置价格表估算；未知模型显示 `—`。
- 收起面板时可在精灵下方显示今日 token 徽标。

> 日志目录可通过环境变量 `DESKPET_AI_USAGE_CLAUDE_DIR` / `DESKPET_AI_USAGE_CODEX_DIR` 覆盖，便于测试。

## 4. 独立窗口

### 4.1 磁盘分析（`analyzer`）

- 全树扫描指定根目录，展示 squarified treemap。
- 支持深度 1–4、按大小 / 文件数等指标切换、过滤。
- 标记目录 / 文件后可查看大小、生成删除计划、执行回收站 / 永久删除。
- 「值得看看」侧栏列出顶层可回收大目录（≥64 MB）。
- 树缓存按 `scanId` 保留最近 2 份，10 分钟过期；窗口关闭时释放。

### 4.2 图库（`images`）

- 添加图库目录（根目录自动按全盘扫描，跳过系统目录）。
- 增量扫描：size + mtime 未变跳过；解析尺寸、EXIF 拍摄时间、相机。
- 缩略图长边 512，落盘缓存，通过 `img://` 协议展示。
- 视图：照片、收藏、标签、重复项；历史文档索引会在启动时自动清理。
- 标签：新增 / 重命名 / 删除 / 给条目标记。
- 精确去重：同尺寸文件计算 blake3 → 分组 → 批量删除。
- 删除走系统废纸篓；条目删除同时清理缩略图。

### 4.3 文档管理（`docs`）

- 添加文档目录，增量扫描并索引文件名、扩展名、大小、修改时间。
- 按目录、扩展名、关键词筛选，支持排序与分页（每页 200）。
- 可直接转 Markdown、复制路径、在文件夹中显示、移入废纸篓。
- 与图库分表，互不干扰。

### 4.4 接口请求（`http`）

同 3.5，面板内是入口，实际编辑与响应展示在独立窗口（最小 760×560）。

### 4.5 文本对比（`textdiff`）

同 3.9，独立窗口（最小 760×560）。

### 4.6 悬浮监控条（`monitorbar`）

- 托盘菜单或监控工具打开 / 关闭。
- 无边框、透明、置顶、不占任务栏、跨工作区可见。
- 可拖动，位置存 `localStorage`；宽度按分区开关自适应。
- 支持鼠标穿透；主窗口与悬浮条通过事件同步分区、刷新间隔与穿透状态。

## 5. 通知与提醒

| 类型 | 触发 | 表现 |
| --- | --- | --- |
| 番茄钟系统通知 | 专注 / 休息结束 | 系统通知中心 |
| 番茄钟提醒浮层 | 阶段结束 | `notify` 窗口大字提示，点击 / Esc 关闭 |
| 更新提示 | 折叠态检测到新版本 | 独立更新小窗；可忽略该版本 |

## 6. 账户与同步

### 6.1 登录

1. 打开「账户」标签，输入手机号与密码。
2. 服务端返回验证模式（图形码 / 滑块 / 无）。
3. 图形码：输入图片字符；滑块：拖动滑块到目标位置。
4. 登录成功保存 token，并随实时通道 Hello 上报登录态用户资料。

### 6.2 云同步开关

- 收藏同步与剪贴板同步分别开关，均依赖登录 token。
- 未登录时开关不可用，提示先登录。
- 启动、打开对应页面、手动操作与 5 分钟节流共同触发拉取。
- 同步失败不会阻塞本地功能，错误会提示并可重试。

### 6.3 冲突处理

- 收藏：以 `update_time` 做 last-write-wins；云端旧数据不会覆盖本地较新的编辑。
- 剪贴板：按条目 id upsert；云端删除列表会同步删除本地。
- 服务端时间统一 UTC `YYYY-MM-DD HH:MM:SS`，前端做 ISO 归一，避免时区问题。

## 7. 数据、隐私与清理

- 所有业务数据默认只存本地 SQLite 与 `settings.json`。
- 会联网的场景：
  - 登录 / 注册与云同步（`hub.htui.cc`）；
  - 实时通道（`hub.htui.cc` gRPC）；
  - 检查更新（hub / GitHub Releases）；
  - AI 对话（用户配置的模型服务）；
  - 收藏仓库数据刷新（GitHub / Gitee 公开 API）；
  - 用户主动发起的 HTTP 请求工具。
- 剪贴板图片、图库缩略图、头像、启动器图标都落在应用数据目录，不写入系统其他位置。
- 删除磁盘文件默认走系统回收站；永久删除必须经过复核清单。
- 卸载应用后，应用数据目录需要手动删除才能彻底清除。

## 8. 行为边界速查

| 场景 | 当前行为 |
| --- | --- |
| 精灵透明边角 | 仍会拦截点击，暂不支持点击穿透 |
| macOS 原生全屏应用 | `alwaysOnTop` 无法覆盖 |
| 剪贴板图片云同步 | 不同步，仅本地 |
| 图库 HEIC / RAW | 不支持 |
| 扫描版 PDF | 返回 `needs_ocr`，不自动 OCR |
| Windows 深浅模式 / 静音 | 不支持 |
| 语言切换 | 立即生效并重建托盘菜单 |
| 应用名修改 | 立即更新面板与托盘提示 |
| 主题 / 主题色 | 主窗口与已打开的独立窗口各自在启动时同步；修改后新开窗口生效 |
| 番茄钟完成次数 | 仅当前会话内存，不持久化 |
| 面板尺寸 | 记住用户手动调整的大小；重启后恢复 |
| 精灵位置 | 持久化到 `settings.json`，重启恢复并钳制到屏幕内 |
